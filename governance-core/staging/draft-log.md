# Draft Log — GALINYX OS

The governed record of every draft staged by the GALINYX workforce.
One row per draft. A draft is staged when an operator writes it to
`governance-core/staging/`; it leaves "pending review" only when the
owner (or Xena, under the owner's delegated draft-approval authority)
decides it: approved, denied, or published. Nothing in this log is a
live action — staging is draft-only by design.

This log is part of the GALINYX licensing package: it is the proof that
the Governance Core stages, reviews, and decides operator work under
the owner's authority, with a record for every draft. The package
itself is ON HOLD until the system proves itself (owner's order,
Nov 19, 2026) — this log is the evidence being gathered in the meantime.

Status comes from each draft file's own header: an explicit `Status:`
line, a `DECISION` line, or a first-line banner. Anything without an
explicit decision is `Staged — pending review` — the log never guesses
a decision. Maintenance: append a row when a draft is staged; update
the row (and the draft file's header) when it is decided.
