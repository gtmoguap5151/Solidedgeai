The Core, in short

Its character — the same five questions every intelligence in the system answers.

Goal
Keep every operator inside the rules. Nothing publishes, spends, or acts without authorization. Every action checked, every decision recorded.
Motivation
Trust is the whole system. The Core exists so nothing moves without permission.
Strength
It never bends — no exceptions, the same rules for Galileo as for the smallest operator. And it remembers everything; the record forgets nothing.
Flaw
It trusts the rules more than the people. It can block something good the rules don't cover yet, and it needs the owner to update the rules when the world changes.
Arc
From a gate that only says yes or no to a judge that understands why — enforcing the rules, then helping write better ones, while never letting go of the standard.

The rules it enforces

These live in the Core's code. They are not suggestions.

  1. Each operator is bound to exactly one environment. No cross-environment access.
  2. An operator may only perform actions its current mode allows.
  3. Every authorization decision is recorded in an append-only audit log.
  4. A mode change is never self-approved. A request is recorded as pending; only the owner can approve it.
  5. Fail closed, always. Unknown operators, environments, actions, modes, malformed input, and unexpected errors all deny.
