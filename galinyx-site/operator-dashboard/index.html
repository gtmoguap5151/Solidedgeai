Activity & audit

The Governance Core keeps an append-only audit log of every authorization decision it makes.

No entries are shown here because this page does not invent activity. When the core runs, each decision it records — allowed or denied, with a timestamp — goes into its audit log, and that log is the record. Run node governance-core/src/demo.mjs in the repository to see the core log real decisions.
