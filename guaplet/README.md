# Guaplet

**Earn. Learn. Move Forward.**

Guaplet is a production-first consumer money education and earning-opportunity app. This folder is the temporary GitHub source of truth while Guaplet is bootstrapped at $0 cost.

## Current production scope

- Supabase authentication
- Money University backed by real published curriculum
- Lesson progress tracking
- Vetted earning-opportunity marketplace backed by production data
- Saved opportunities and application tracking
- Transparent disclosures, including how Guaplet earns revenue
- No fake balances, bank accounts, cards, transfers, or investment screens

## Regulated-money boundary

Wallets, P2P transfers, direct deposit, debit cards, cash-out and related banking functions remain absent until a real regulated banking program is approved and connected.
